# Лабораторная работа №3 — «Доска публикаций»

## Файлы
- `index.html` — разметка страницы
- `styles.css` — стили
- `app.js` — логика (fetch, async/await, DOM)

## Как запустить
Открой `index.html` в браузере.

## Проверка
1. Нажми «Загрузить публикации» — появятся 5 записей с заголовками и текстом.
2. Отправь пустые поля или одни пробелы — появится ошибка, запрос не отправляется.
3. Отправь корректные заголовок и текст — успешный ответ (HTTP 201), публикация появится на странице.
4. Проверка 404: замени в `app.js` адрес `POSTS_URL` на `https://jsonplaceholder.typicode.com/postz` — появится ошибка, кнопку можно нажать снова. После проверки восстанови правильный адрес.
